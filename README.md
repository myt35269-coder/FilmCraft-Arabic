# FilmCraft Arabic

مشروع مجتمعي لإضافة اللغة العربية إلى واجهة FilmCraft وتحسين تجربة استخدامها.

## الهدف
- ترجمة القوائم والأزرار والنوافذ ورسائل الواجهة إلى العربية.
- الاستفادة من بنية دعم النصوص ثنائية الاتجاه والخطوط العربية الموجودة في مصدر FilmCraft، ثم اختبارها وتوسيعها عند الحاجة.
- الحفاظ على النصوص التقنية وأسماء الملفات والاختصارات بطريقة واضحة ومتسقة.

## الحالة الحالية
- يستهدف تكامل التعريب إصدار FilmCraft **0.18.0** من المصدر الرسمي.
- يضيف مسار البناء اللغة العربية إلى مصدر التطبيق ويضمّن كتالوج المشروع:
  `crates/ui-egui/src/i18n/ar.tsv`
- يفحص سير العمل `auto-translate.yml` أحدث إصدار رسمي يوميًا، ويبني معاينة معرّبة عند اكتشاف تحديث. بعد نجاح الاختبارات، يفتح طلب سحب لتحديث الإصدار المستهدف؛ لا يدمج التغييرات تلقائيًا.
- الكتالوج **جزئي**؛ النصوص التي لم تُترجم ستظهر باللغة الإنجليزية. ينتج سير البناء تقريرًا بالنصوص المتبقية.
- ما زال يلزم نجاح الاختبارات والبناء ومراجعة RTL يدويًا قبل اعتبار النسخة جاهزة للاستخدام.

## طريقة الكتالوج
كل سطر يستخدم ثلاثة أعمدة مفصولة بعلامة TAB:
`context<TAB>English source<TAB>Arabic translation`

اترك العمود الأول فارغًا للترجمات العامة. لا تغيّر أسماء المتغيرات مثل `{name}` أو `{n}` داخل الجمل.

## تنبيه
هذا المستودع لا يغيّر تثبيت FilmCraft الموجود على جهاز المستخدم ولا ملفات مشاريعه. البناء يخص نسخة معاينة مستقلة ولا يثبتها تلقائيًا.

لتمكين طلبات السحب الآلية، فعّل في إعدادات المستودع **Settings → Actions → General → Allow GitHub Actions to create and approve pull requests**.

## المصدر والترخيص
يُراجع ترخيص المصدر الأصلي وإشعاراته قبل دمج أي ملفات كود من المشروع upstream. هذا المستودع يحتوي ترخيصه الخاص؛ لا يعني ذلك إعادة ترخيص ملفات المصدر الأصلية.
