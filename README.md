# FilmCraft Arabic

مشروع مجتمعي لإضافة اللغة العربية إلى واجهة FilmCraft وتحسين تجربة استخدامها.

## الهدف
- ترجمة القوائم والأزرار والنوافذ ورسائل الواجهة إلى العربية.
- الاستفادة من بنية دعم النصوص ثنائية الاتجاه والخطوط العربية الموجودة في مصدر FilmCraft، ثم اختبارها وتوسيعها عند الحاجة.
- الحفاظ على النصوص التقنية وأسماء الملفات والاختصارات بطريقة واضحة ومتسقة.

## الحالة الحالية
- أُنشئ فرع العمل `arabic-localization` حتى تبقى `main` دون تغيير.
- أُضيفت مسودة أولية لكتالوج العربية في:
  `crates/ui-egui/src/i18n/ar.tsv`
- هذه المسودة **غير مفعّلة داخل التطبيق بعد**؛ يلزم تسجيل اللغة `ar` في نظام اللغات وربط الكتالوج، ثم إجراء اختبارات الترجمة وRTL وبناء نسخة مستقلة.
- الكتالوج جزئي؛ أي نص غير مترجم سيظهر باللغة الإنجليزية إلى أن تكتمل ترجمته.

## طريقة الكتالوج
كل سطر يستخدم ثلاثة أعمدة مفصولة بعلامة TAB:
`context<TAB>English source<TAB>Arabic translation`

اترك العمود الأول فارغًا للترجمات العامة. لا تغيّر أسماء المتغيرات مثل `{name}` أو `{n}` داخل الجمل.

## تنبيه
هذا المستودع لا يغيّر تثبيت FilmCraft الموجود على جهاز المستخدم ولا ملفات مشاريعه. التفعيل يتطلب بناء نسخة منفصلة من المصدر بعد اكتمال التعديلات والاختبارات.

## المصدر والترخيص
يُراجع ترخيص المصدر الأصلي وإشعاراته قبل دمج أي ملفات كود من المشروع upstream. هذا المستودع يحتوي ترخيصه الخاص؛ لا يعني ذلك إعادة ترخيص ملفات المصدر الأصلية.
